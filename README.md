# anomaly_detection

Обнаружение мошеннических банковских транзакций с использованием методов машинного обучения
Задача: Обнаружение аномальных (мошеннических) банковских транзакций на основе анализа истории операций, характеристик клиента и параметров транзакции. Реализовано с использованием пяти алгоритмов машинного обучения для обнаружения аномалий (Isolation Forest, Local Outlier Factor, One-Class SVM, Autoencoder, GAN) и комплексной обработки данных.

Метрики для оценки качества моделей:

Score Gap: Разница средних scores между аномальными и нормальными транзакциями (чем больше, тем лучше)

ROC-AUC: Площадь под ROC-кривой (0.5 - случайная модель, 1.0 - идеальная модель)

Лучшая модель: Autoencoder демонстрирует наилучший баланс между Score Gap (1.009) и ROC-AUC (0.893), показывая высокую способность к обнаружению аномалий при минимальных ложных срабатываниях.

Дополнительные метрики для автоэнкодера: ошибка реконструкции (MSE), процент обнаружения аномалий и ложные срабатывания.

Технологии:

Обработка данных: pandas, numpy

Визуализация: matplotlib, seaborn

Предобработка и оценка моделей: scikit-learn

Машинное обучение: scikit-learn для классических моделей, TensorFlow/Keras для нейросетей

1. Убедитесь, что у вас установлен Python 3.8 или выше и необходимые библиотеки, при необходимости выполните:

    pip install pandas numpy matplotlib seaborn scikit-learn tensorflow keras joblib
